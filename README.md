# Лабораторная работа №1 — АиСД

**Вариант 6:** полутоновые изображения.  
**Задача 3:** закрашенный круг.

## Что делает программа

Шаблонный класс `Image<T>` — полутоновое изображение произвольного размера.  
Поддерживаемые типы элементов: `bool`, `char`, `float`, `short`.

Реализовано:
- конструктор `(ширина, высота, флаг)` — нулями или случайно;
- правило трёх (copy ctor, `operator=`, деструктор);
- `operator()` — доступ к элементу с проверкой индекса;
- `operator+`, `operator-`, `operator*` — поэлементные (с поддержкой разных размеров);
- `operator*`, `operator+` со скаляром (с коммутативностью);
- `operator!` — инверсия;
- `operator==`, `operator!=` — сравнение с точностью `epsilon`;
- `operator<<` — вывод;
- `fill_ratio()` — коэффициент заполнения;
- `draw_filled_circle()` — задача 3 (круг, вне класса).
